Settings

Engines are crispz family apps (klein, qwen-edit, flux3...). URL = the running instance; folder = its install dir so Dataset Studio can start it (port from the URL, log in logs/). One engine runs at a time: two apps do not fit on one GPU.

Output

Same layout as the crispz apps: <folder>/YYYY-MM-DD/<project>_<YYYYMMDD-HHMMSS>/ holds the NNN.png + NNN.txt pairs of one export (a lot), with the ZIP of the same name beside it. Nothing is overwritten.
